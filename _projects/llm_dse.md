LLM-DSE uses large language model agents to search high-level synthesis directive parameters for hardware accelerators {% cite wang2025llmdse %}. Coordinated explorer/critic agents reason about performance feedback from downstream tools, outperforming classical black-box design-space-exploration methods on the HLSyn benchmark.

[Code on GitHub](https://github.com/Nozidoali/LLM-DSE).
