A cost-generic resubstitution framework that lets users plug arbitrary cost functions (area, depth, fanout, and beyond) into logic optimization {% cite wang2022costgeneric %}, generalized into the AnySyn framework {% cite wang2023anysyn %}. The algorithm ships in [mockturtle](https://mockturtle.readthedocs.io/en/latest/algorithms/cost_generic_resub.html), the EPFL open-source logic network library, and won 1st place in the IWLS 2022 programming contest.
